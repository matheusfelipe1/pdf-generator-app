# Plan

## Phase 1 - Foundation

- Initialize React Native/Expo project.
- Add required dependencies for file picking, file reading and PDF generation.
- Define the project structure using MVVM.

## Phase 2 - Domain and services

- Create the document models.
- Build parsing services for HTML, TXT and Markdown transformations.
- Implement the export service to save PDF files into the Documents directory.

## Phase 3 - View model and UI

- Create the view model responsible for file selection, preview generation and PDF export orchestration.
- Build the modern screen with controls for input type, content type and preview.
- Add status messaging and save flow feedback.

## Phase 4 - Validation

- Run TypeScript validation.
- Review the app behavior for iOS-specific flows and fix any required issues.
- Capture final app instructions and usage notes.
