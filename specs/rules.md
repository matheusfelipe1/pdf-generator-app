# Rules

1. Use React Native with Expo as the app base.
2. Implement the MVVM pattern: models, services, view models and screens.
3. Keep the UI iOS-first but maintain responsive, modern styling.
4. Prefer explicit, testable services for parsing and PDF creation.
5. Document all source files in English using concise JSDoc comments.
6. Avoid business logic in UI components.
7. Ensure HTML preview and exported PDF use the same rendering pipeline.
8. Save exported PDFs into the user Documents directory using the file system APIs.
