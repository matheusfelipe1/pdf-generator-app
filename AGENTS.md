# Agent Task: PDF Generator App

You are responsible for building a React Native app that creates PDFs from text or file input. The implementation must:

- follow the MVVM pattern
- support HTML, TXT and Markdown content
- include a preview screen before export
- save the generated PDF into the device Documents folder when the user taps Save
- prioritize an iOS-first design and polished layout
- document all code in English

## Constraints

- Use Expo + React Native.
- Keep the code clear and performance-aware.
- Use dedicated services for document parsing and PDF export.
- Do not mix business logic into the screen layer.

## Expected output

- A production-ready app skeleton with clear source organization
- A modern UI and preview experience
- SDD artifacts under `specs` with requirements, plan, rules, spec and tasks
- Developer-friendly documentation in `README.md`
